Game Story

เจ้าหญิงตื่นขึ้นมากลางความฝันและต้องหาทางหนีออกจากมันให้ได้ ผู้เล่นต้องต่อสู้กับเหล่ามอนสเตอร์ หลบหลีกกับดัก และค่อยๆ ปะติดปะต่อเรื่องราวผ่านแต่ละด่าน

Game Style

เกมพิกเซลอาร์ต 2 มิติ พื้นหลังและเสียงประกอบน่ารักสดใส ผสมกับเนื้อเรื่องที่มีทั้งด้านมืดและด้านสว่าง พร้อมเกมเพลย์แบบคลาสสิก

2D Platformer Starter Kit

ชุดเริ่มต้นนี้รวบรวมกลไกพื้นฐานที่จำเป็นสำหรับการสร้างเกม 2D Platformer แบบครบวงจรด้วย Godot 4.7 ออกแบบมาเป็นสื่อการเรียนรู้แบบลงมือทำสำหรับนักศึกษาในรายวิชา Computer Game Development คณะวิทยาการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

Features

  • Game Menu — เมนูหลักแบบง่าย (Menu.tscn) พร้อมปุ่ม Start และ Exit
  • Mobile & Web Design — มีปุ่มควบคุมบนหน้าจอ เล่นได้ทั้งมือถือ แท็บเล็ต และเบราว์เซอร์
  • Platformer Controller — การเคลื่อนที่และกระโดดแบบ responsive รองรับ double jump ปรับค่าได้จาก Inspector
  • Weapon System — ยิงลูกไฟที่มีฟิสิกส์เด้งได้ กำจัดศัตรูและเพิ่มคะแนน
  • Enemy AI — ศัตรูเดินลาดตระเวน กลับทิศเมื่อชนกำแพง และตรวจจับผู้เล่นด้วย raycasting
  • Enemy Spawner — สุ่มสร้างศัตรูตามเวลา ปรับความเร็ว ดีเลย์ และจำนวนสูงสุดได้
  • Animated Player — แอนิเมชัน idle, walk, jump, attack พร้อม sprite flip อัตโนมัติ
  • Particle Effects — เอฟเฟกต์วิ่ง ระเบิดตอนตาย และแฟลชแดงเมื่อโดนโจมตี
  • Damage & Health System — โดนศัตรูแล้วมี knockback และช่วง invincibility แสดง HP bar และจำนวนชีวิต
  • Save & Load — บันทึกตำแหน่ง คะแนน ชีวิต และการตั้งค่าเป็นไฟล์ JSON
  • Sound & Music Toggle — บันทึกการตั้งค่าเสียงถาวร พร้อมปุ่ม mute/unmute
  • Score System — เก็บเหรียญหรือกำจัดศัตรูเพื่อเพิ่มคะแนน อัปเดตแบบเรียลไทม์
  • Demo Levels — ด่านตัวอย่าง 2 ด่านที่ค่อยๆ เพิ่มความท้าทาย
  • Level Management — เปลี่ยนฉากอย่างลื่นไหลด้วย autoload transition manager
  • Beginner-Friendly Code — ทุกสคริปต์มีคอมเมนต์ อ่านง่าย แก้ไขและต่อยอดได้สะดวก

Getting Started

  1. เปิดโปรเจกต์ใน Godot 4.7 หรือใหม่กว่า
  2. กด F5 หรือคลิก Play เพื่อเข้าสู่เมนูหลัก
  3. ใช้ A/D หรือ ลูกศรซ้าย/ขวา เพื่อเดิน กด Space เพื่อกระโดด และ X เพื่อยิง
  4. บนมือถือหรือเว็บ ใช้ปุ่มควบคุมที่แสดงด้านล่างหน้าจอ
  5. เก็บเหรียญ กำจัดศัตรู หลบกับดัก แล้วไปถึงประตูเพื่อจบแต่ละด่าน

Project Structure

Scenes/
├── Actors/           # Player, enemies, and spawners
├── Levels/           # Level scenes, base level template, and UI
├── Managers/         # GameManager, SceneTransition, AudioManager
└── Prefabs/          # Reusable objects (bullet, coin, potion, door, button)

Assets/
├── Fonts/            # Custom fonts
├── Icons/            # UI icons
├── Sound/            # BGM and SFX
├── Spritesheet/      # Character and tile sprites
└── Textures/         # Particle and effect textures

Inspector Tips

  • Player: เปิด double_jump เพื่อใช้กระโดดสองครั้ง ปรับ move_speed, jump_force, shoot_cooldown_time และ bullet_lifetime ได้ใน Inspector
  • Enemy Spawner: ตั้งค่า enemy_scenes, speed_range, respawn_time และ max_instance เพื่อควบคุมพฤติกรรมและความหนาแน่นของศัตรู
  • Bullet: ปรับ speed และ lifetime เพื่อเปลี่ยนความรู้สึกของกระสุน

Saving

  • กดปุ่ม Save ที่มุมขวาบนเพื่อบันทึกความคืบหน้า
  • เกมจะบันทึกตำแหน่งผู้เล่น คะแนน จำนวนชีวิต และการตั้งค่าเสียง
